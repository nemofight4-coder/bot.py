# 🚀 Market Intelligence AI Bot (monobank Edition)

Інтелектуальний помічник для продуктового менеджера, розроблений для автоматизації аналізу ринку та пріоритезації беклогу.

## 🛠 Технологічний стек
* **Мова:** Python 3.10+
* **Бібліотека:** aiogram 3.x (асинхронна робота з Telegram API)
* **AI Engine:** OpenAI API (GPT-4 модель)
* **Infrastructure:** Deployment on Render (Web Service)

## 🌟 Ключові функції
* **Аналіз ринку:** Збір та обробка даних про конкурентів у реальному часі.
* **Пріоритезація беклогу:** AI-скоринг завдань на основі вхідних метрик.
* **Аналіз відгуків:** Обробка фідбеку користувачів (Social/AppStore) через NLP.
* **Безпека:** Використання змінних оточення (Environment Variables) для захисту API-ключів.

## 🚀 Як запустити
1. Клонувати репозиторій.
2. Встановити залежності: `pip install -r requirements.txt`.
3. Налаштувати змінні оточення `TELEGRAM_TOKEN` та `OPENAI_API_KEY`.
4. Запустити: `python bot.py`.
